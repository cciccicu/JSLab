# 使用云空间和 JS 市场

你可以在网页上编辑脚本，再下载到手环运行；也可以把手环上的作品上传保存，或发布到 JS 市场让其他人使用。

如果只是想找一个脚本试试，可以直接 [打开 JS 市场](/jslab-cloud/workspace/market)。浏览和下载不需要登录或激活。

## 把手环连接到自己的账户

1. 在手环打开 JSLab 的云设置，点击“生成配对二维码”。
2. 用手机扫描二维码，打开网页并登录。
3. 确认配对，然后回到手环，等待出现配对成功的提示。

不方便扫码时，也可以登录 [云空间](/jslab-cloud/workspace)，打开“设备管理”，输入手环显示的 8 位配对码。

配对码过期了就重新生成。网页确认之后，还要等手环显示成功，才能开始使用。以后不想让某台设备继续访问账户，可以在“设备管理”中撤销它的授权。

## 激活云空间

在网页云空间点击“充值与激活”，输入有效激活码兑换。首次兑换会开通云空间和 AI，并赠送 ¥2.00 的 AI 余额；之后每个未使用的激活码增加 ¥3.00。

还没有激活码？可以 [购买激活码](https://catfk.com/shop/788UHUA9)，购买后回到“充值与激活”兑换。

兑换完成后，在手环云页面刷新账户状态，就能看到更新后的激活状态和余额。

## 在网页上写代码，在手环上运行

1. 打开网页云空间，点击“新建”。
2. 输入文件名，例如 `hello.js`，写入代码后点击“保存文件”。
3. 在手环打开云空间，刷新文件列表，选择刚才的文件并下载。
4. 回到手环本地工作区，打开下载的文件，点击运行。

下次在网页上修改后，保存云文件，再在手环重新下载。手环上改过代码，也需要主动上传，网页里才会看到更新。

**上传和下载都需要你亲自操作。** 编辑或保存本地文件后，云端不会自动跟着修改。两边都改过同一个文件时，先确认要保留哪一份，避免覆盖需要的内容。

## 整理云文件

在搜索框输入文件名，可以快速找到文件。点击“编辑”修改名字或代码，再点击“保存文件”；删除按钮也在编辑窗口中。

文件名以 `.js` 结尾，尽量简短、容易辨认，例如 `计数器.js`。名字最长 128 个 UTF-8 字节，中文通常占 3 个字节；单个脚本的代码最多 48 KiB。

云空间没有历史版本或回收站。覆盖、删除重要文件前，先在手环保存一份需要保留的代码。

## 从市场找一个作品试试

在 JS 市场搜索名称或用途，打开详情，先读作者说明，再查看代码。网页可以直接下载源码；手环下载时会让你选择本地文件名。

如果想稍后在网页继续编辑，可以登录后点击“保存到云空间”。这会得到你自己的一份文件，以后修改它不会影响作者的作品。

脚本可以使用 JSLab 提供的系统功能。遇到需要联网、访问文件等操作的作品，运行前确认这些行为符合你的预期。

## 把自己的作品分享出去

在网页云文件旁点击“发布到市场”，代码会自动填入发布表单。接着填写名称、说明和标签，再提交审核。

说明可以写得具体一些：这个脚本解决什么问题，打开后应该怎样操作，是否需要网络。比如：

> 一个离线计数器。点击“加一”记录次数，点击“清零”重新计数。关闭后不会保存本次结果。

在手环上发布时，从本地脚本库选择要分享的文件，填写资料后提交即可，不必先上传到云空间。

提交后，在网页“我的发布”查看审核状态。修改已发布的作品也需要审核，通过之前，其他人看到的仍是之前的版本。云空间里的代码改了，并不会自动更新市场作品；要到“我的发布”编辑并重新提交。

删除云文件不会撤下已经发布的作品。需要撤下时，请到“我的发布”删除市场条目。

## 让 AI 帮你起草代码

在手环打开 AI 生成功能，把想做的事情和操作方式写清楚。例如：

> 做一个离线计数器，显示当前次数，提供“加一”和“清零”两个按钮。关闭后不需要保存次数。

比起只写“做一个工具”，这样更容易得到接近预期的结果。生成后先读一遍代码，再运行测试；确认可用后保存。

AI 会消耗余额，费用根据本次输入和输出的 Token 数量计算。Token 是模型计算文本长度的单位。余额不足时，到网页“充值与激活”查看余额并兑换充值码。

## 遇到问题时

| 看到的情况 | 可以怎样处理 |
| --- | --- |
| 网页确认了，手环还没有配对成功 | 返回手环等待完成；配对码过期时重新生成 |
| 提示设备授权失效 | 在手环重新发起配对 |
| 编辑过的代码没有出现在另一端 | 保存后主动上传或下载，并刷新目标文件列表 |
| 提示云空间未激活 | 在网页兑换激活码，再刷新手环账户状态 |
| AI 提示版本不兼容 | 更新 JSLab 应用；若仍有提示，请让站点管理员检查云端版本 |
| AI 服务未配置或暂时不可用 | 稍后重试，或联系站点管理员 |
| 修改市场作品后仍显示旧内容 | 到“我的发布”查看本次修改是否已经审核通过 |
