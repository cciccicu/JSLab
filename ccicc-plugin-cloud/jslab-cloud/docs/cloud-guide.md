# 云空间与 JS 市场

云空间用于保存你的当前脚本文件，JS 市场用于发布和获取独立的脚本快照。两者的内容与权限分别管理。

## 设备配对

从手环发起配对，再登录网页确认一次性配对码。网页“设备管理”可以输入配对码、查看等待完成的配对和已配对设备，并撤销设备授权。

配对码过期时，在手环重新生成。网页确认后需要返回手环完成交换；不要将配对码或设备令牌分享给他人。撤销授权后设备需要重新配对。

## 激活与充值

进入云空间的“充值与激活”查看云空间、AI 激活状态与 AI 余额，输入有效激活码兑换。首次有效兑换会激活账户并赠送 ¥2.00；之后每个未使用的激活码增加 ¥3.00。

配对和市场发布不需要激活。创建、编辑云端文件和保存市场脚本到云空间需要云空间激活；AI 需要 AI 激活和足够余额。

## 管理云端文件

- “新建”打开源码编辑器；填写合法的 `.js` 文件名并保存。
- 搜索框按文件名查找，点击“编辑”查看或修改源码。
- 在编辑器中可保存或删除当前文件。手环可主动下载云文件到本地工作区。
- 上传和下载由手环或网页上的操作主动发起，云空间不执行后台自动同步。

文件名限制为 128 个 UTF-8 字节，中文通常占多个字节。源码最大 48 KiB。已有 `.ui.js` 文件作为普通文件保留。

云空间不提供可恢复的版本历史。覆盖或删除前，请下载需要保留的内容。删除云文件不会删除已经发布的市场条目。

## 浏览与下载市场脚本

JS 市场提供搜索、脚本详情、作者页面和源码下载，公开内容无需登录。下载时会生成合法的 `.js` 文件名；手环可以在“另存为”中修改本地名称。

登录并激活云空间后，也可以点击“保存到云空间”。保存产生你自己的云文件，后续编辑不会改动市场中的原始发布内容。

运行前检查源码。市场脚本拥有 JSLab 的运行权限，可以调用可用系统接口。

## 发布和更新脚本

网页从云文件点击“发布到市场”时自动填入代码，市场名称、说明和用途标签仍需填写。提交后等待审核，在“我的发布”查看状态、编辑或删除自己提交的内容。

手环发布时从本地脚本库选择源码，填写资料后提交；设备需要配对，云空间不必激活。

已发布内容是独立快照。后续修改需重新审核，审核通过前线上仍展示之前通过的版本。被拒绝后根据说明修改再提交；管理员可处理审核和举报。

## 使用 AI 生成代码

在手环选择 AI 生成功能，填写需求并提交。AI 需要设备配对、AI 激活、足够余额和管理员配置的生成服务。生成后先查看代码，再运行和保存。

费用按服务端配置的输入、缓存输入和输出 Token 价格结算。生成和市场审核使用独立配置。若模型服务未配置，请联系站点管理员。

## 常见问题

### 云空间未激活

登录网页兑换有效激活码，再在手环云页面主动刷新账户状态。市场浏览和下载仍可使用。

### 设备令牌无效

设备授权可能已撤销或账户不可用。确认账户状态后，在手环重新发起配对。

### 文件没有自动更新

云空间采用手动上传、下载。请主动操作并核对目标文件，覆盖前先备份重要内容。

### AI 提示运行契约不匹配

设备和云插件必须共同支持 `jslab-unified-open-ui`。更新到相互兼容的版本后再试，不要根据相同版本号推断运行契约一致。

### 修改市场脚本后仍看到旧代码

更新需要审核。查看“我的发布”中的待审或拒绝状态，审核通过后才会替换公开内容。
