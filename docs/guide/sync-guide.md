# 手机与 AstroBox 同步

> 最低支持版本：源码同步和云服务网络桥接以设备端 JSLab 2.0.0 为基线；脚本数据同步需要 2.0.4。Android 同步器和 AstroBox 插件使用各自的版本号，还需具备对应功能。

同步器直接管理设备里的本地脚本，适合在手机上编辑较长代码，或把文件下载到电脑备份。它与云空间是两种工作方式：同步器保存到设备，云空间保存到服务器。

## 选择一个配套端

| 配套端 | 连接由谁提供 | 获取方式 |
| --- | --- | --- |
| Android 同步器 | 小米运动健康 | [JSLab 下载页](https://ccicc.icu/jslab-cloud/downloads) |
| AstroBox 的 JSLab Sync 插件 | AstroBox | AstroBox 官方插件源，或 [插件发布仓库](https://github.com/cciccicu/JSLab-AstroBox-Plugin-Release) |

两者都能读取、编辑、新建、重命名、删除和传输脚本。源码同步不需要激活云空间。字体更换目前尚未开放，入口显示“即将上线”。

## 连接 Android 同步器

1. 在小米运动健康中配对并连接设备，确认设备已安装 JSLab。
2. 在手机安装并打开 JSLab Android 同步器。
3. 首次使用时，按小米运动健康的提示授予设备管理权限。
4. 同步器会尝试打开设备上的 JSLab 并建立连接。连接成功后显示脚本列表。
5. 没有成功时，先保持设备端 JSLab 打开，再点击首页“重试握手”。这里的“握手”表示检查双方是否可以通信。

Android 同步器依赖小米运动健康提供的连接。它不能代替设备配对，也没有独立的设备切换流程；切换设备请在小米运动健康中操作。

自行构建或更换来源的安装包可能有签名差异。Android 与设备端 JSLab 需要匹配的包名和签名，建议使用同一发布渠道提供的配套版本。

## 在 AstroBox 中连接

1. 安装 JSLab Sync 插件，并在 AstroBox 中连接目标设备。
2. 确认设备已经安装 JSLab，打开插件。
3. 等待插件显示连接状态和脚本列表；连接不成功时，确认设备端 JSLab 已打开，再刷新或重试。

获取插件时不要与 JSLab 设备端安装包混淆：插件安装在 AstroBox，`.rpk` 安装在手环或手表。

## 编辑、导入和导出脚本

读取已有文件后，在配套端编辑并点击保存，将修改写回设备。在线新建会在设备创建文件；导入本地 `.js` 文件时，同名覆盖需要确认。重命名不会覆盖另一个已有文件。

Android 编辑器支持查找替换、撤销重做、行号跳转和自动换行设置。双指缩放可调整显示字号；底部工具栏提供光标移动、缩进和常用符号。AstroBox 插件使用其内置编辑控件，操作方式以插件页面为准。

需要备份源码时，使用下载或导出，选择手机、电脑上的保存位置。传输完成后，仍需在设备上运行脚本。

## 离线修改与未保存内容

Android 同步器可保留未保存草稿。离开编辑器时选择“保留草稿”，以后从首页继续编辑；设备重新连接后再保存。已有设备文件的草稿与原设备关联，不会自动写入另一台设备。

AstroBox 插件在当前会话中保留编辑内容；关闭插件前，请先保存到设备，或下载需要保留的修改。不要把连接恢复或列表刷新当作自动保存。

## 编辑脚本的数据与设置

JSLab 2.0.4 及以上的设备端配合支持脚本数据同步的同步器，提供“脚本数据”或“编辑脚本数据”入口。2.0.4 的早期测试包可能没有此功能，请使用该版本最新构建。这里编辑的是脚本通过 `script.data` 和 `script.config` 保存的内容，不是源码。

```json
{
  "data": { "count": 12 },
  "config": { "step": 1 }
}
```

保留 `data`、`config` 两个对象，并确保内容是有效 JSON。建议先下载或导出 JSON 备份，再保存修改。

如果脚本在你编辑期间更新了数据，同步器会拒绝覆盖并保留编辑内容。先导出这份修改，再重新读取最新数据，合并后保存。旧设备没有此能力时，入口会提示更新，原有源码同步仍可使用。

源码备份不会自动包含这些数据；复制一个 `.js` 文件也不会复制它保存的记录。

## 用配套端转发云服务请求

在设备“设置 > 传输方式”中，可以选择：

| 选项 | 使用条件 |
| --- | --- |
| fetch 直连 | 设备的原生网络请求可访问所选服务器 |
| JSLabSync 网络桥接 | 配套端已连接，并允许转发 JSLab 云服务请求 |

选择桥接后，保持配套端打开并联网。Android 同步器可在设置里关闭云转发；关闭后或进程被系统回收后，需要重新打开并连接才能继续转发。

网络桥接只用于 JSLab 自身的云账户、云文件、市场和 AI 等请求。它不会把用户脚本中的 `system.http.request()` 自动变成手机网络请求。脚本网络的用法见 [网络请求与连接状态](http.md)。

## 无法同步时

先检查设备是否仍然连接、JSLab 是否打开，再检查双方版本。当前同步器没有另设 48 KiB 源码上限；旧版 AstroBox 插件可能仍有限制，请更新插件。更多情况见 [常见问题与排查](troubleshooting.md)。
