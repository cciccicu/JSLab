# 发现与分享市场作品

> 最低支持版本：设备端浏览、下载和从本地脚本发布以 JSLab 2.0.0 为基线；适配设备选择、点赞与下载统计需要 2.0.4 的最新构建。网页功能由云服务提供，无需安装设备端。

JS 市场用于发现和分享 JSLab 脚本。网页和设备都可以浏览作品；下载后得到的是一份源码，需要在 JSLab 中运行。

[打开 JS 市场](https://ccicc.icu/jslab-cloud/workspace/market) · [下载 JSLab](https://ccicc.icu/jslab-cloud/downloads)

## 使用前需要什么

浏览和下载不要求登录、配对或激活云空间。点赞和发布需要身份：网页端先登录，设备端先在“设置 > 云账户”完成配对，两者都不要求激活云空间。

## 从市场找一个作品试试

在 JS 市场搜索名称或用途，打开详情，先读作者说明，再查看代码。网页可以直接下载源码；手环下载时会让你选择本地文件名。

网页和手环的市场列表、详情均显示下载量和点赞数。网页可在列表或详情点赞，手环可在详情右上角点赞；再次点击可取消。同一账户在网页与已配对设备共用一份点赞状态，每个作品最多计一个赞，无需激活云空间。

下载量从该功能上线后开始累计。网页下载源码或新版设备成功保存市场脚本时会计数；查看代码或取消下载不会计数。统计失败不会影响已经保存的文件。

如果想稍后在网页继续编辑，可以登录后点击“保存到云空间”。这会得到你自己的一份文件，以后修改它不会影响作者的作品。

脚本可以使用 JSLab 提供的系统功能。遇到需要联网、访问文件等操作的作品，运行前确认这些行为符合你的预期。

## 把自己的作品分享出去

在网页云文件旁点击“发布到市场”，代码会自动填入发布表单。接着填写名称、说明、适配设备和标签，核对代码后再提交审核。

说明可以写得具体一些：这个脚本解决什么问题，打开后应该怎样操作，是否需要网络。比如：

> 一个离线计数器。点击“加一”记录次数，点击“清零”重新计数。关闭后不会保存本次结果。

在手环上发布时，从本地脚本库选择要分享的文件，填写资料后提交即可，不必先上传到云空间。

提交后，在网页“我的发布”查看审核状态。更新作品时，在这里编辑并重新提交；审核期间继续提供之前的公开版本，通过后切换到新版本。

删除云文件不会撤下已经发布的作品。需要撤下时，请到“我的发布”删除市场条目。

## 审核状态与版本更新

| 状态 | 接下来做什么 |
| --- | --- |
| 待审核 | 等待处理，在“我的发布”查看进度 |
| 已发布 | 其他用户可以浏览和下载 |
| 已拒绝 | 阅读反馈，修改内容后重新提交 |

市场保存提交时的作品副本，与本地文件和云空间文件分别管理。

## 写一份有用的作品说明

说明用途、打开后的操作步骤、适配设备，以及是否需要联网或额外设置。有保存记录的功能时，解释清零、删除或退出会不会丢失数据。

发布前至少在目标设备上完成主要操作，尝试取消输入和重复打开。不要把个人令牌、账号或其他私人内容一起发布。想将脚本做成独立安装包，可以继续阅读 [导出为独立应用](rpk-guide.md)。
