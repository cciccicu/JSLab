# 选择版本与安装

JSLab 让你在手环或手表上运行 JavaScript 脚本。一个脚本可以是计数器、计算工具或信息展示页面；你可以自己编写，也可以先从 JS 市场下载作品。

你不必一开始就准备所有配套工具。先安装设备端，运行一个本地脚本；需要在大屏幕上编辑时，再选择手机同步器或云空间。

## 怎样看最低支持版本

帮助文档以 **JSLab 2.0.0** 为基线。更早已有的功能统一标为“2.0.0 及以上”，不追溯 1.x；之后加入的功能单独标注版本。除非写明 JSLab Cloud 或配套端，版本号都指安装在手环、手表上的 JSLab。

每篇功能文档开头的版本说明适用于本页全部功能，另有标注的项目以自己的版本为准。版本号对应该版本的最新构建；同号早期测试包可能还没有后续加入的能力。

| 功能 | 最低支持版本 | 继续阅读 |
| --- | --- | --- |
| 新建、编辑、运行、日志与文件管理 | 设备端 2.0.0 | [设备端操作](watch-guide.md) |
| 脚本控制、对话框、数据与设置 | 设备端 2.0.0 | [脚本基础](script-basics.md) · [对话框](runtime-api.md) · [保存数据](script-storage.md) |
| 基础 UI、状态、布局与二维码 | 设备端 2.0.0 | [交互界面](ui-api.md) |
| 设备、文件、网络、传感器等系统接口 | 设备端 2.0.0；还需固件支持 | [设备接口](system-api.md) |
| 云账户、云文件、AI、市场与源码同步 | 设备端 2.0.0；还需对应服务或配套端 | [云空间](cloud-guide.md) · [同步](sync-guide.md) |
| 社区版选择官方或第三方服务器 | 设备端 2.0.2 社区版 | [选择服务器](cloud-guide.md) |
| 读取布局宽度 `ui.getWidth()`、REDMI Watch 设备适配 | 设备端 2.0.4 | [适配布局](ui-api.md) |
| 取消源码、UI 文字与脚本存储的固定容量上限 | 设备端 2.0.4；仍受设备资源限制 | [编辑器](watch-guide.md) · [UI](ui-api.md) · [存储](script-storage.md) |
| 通过同步器编辑、备份和恢复脚本数据 | 设备端 2.0.4；配套端也需支持 | [脚本数据同步](sync-guide.md) |
| 市场适配设备选择、点赞与下载统计 | 设备端 2.0.4 | [JS 市场](market-guide.md) |

仅浏览云端网页不要求安装设备端。独立应用使用导出时的运行引擎；需要新 API 时应重新导出，不能通过更新设备上的 JSLab 给旧独立应用增加能力。

## 先了解几个入口

| 名称 | 在哪里使用 | 用来做什么 |
| --- | --- | --- |
| JSLab 设备端 | 手环或手表 | 保存、编辑和运行脚本，浏览市场 |
| JSLab Cloud | 手机或电脑浏览器 | 编辑云文件、管理设备、发布作品和打包独立应用 |
| Android 同步器 | Android 手机 | 直接读写设备里的脚本，也能编辑脚本保存的数据 |
| JSLab Sync 插件 | AstroBox | 在 AstroBox 中管理设备里的脚本和数据 |

**本地新建、编辑和运行脚本无需激活云空间。** 如果脚本自身要联网或使用设备功能，还需满足该功能的条件。

## 下载与设备相符的安装包

打开 [JSLab 下载页](https://ccicc.icu/jslab-cloud/downloads)，按照设备选择安装包。设备端安装包的扩展名是 `.rpk`，Android 手机安装包的扩展名是 `.apk`。

| 下载项 | 怎样选择 |
| --- | --- |
| 小米手环 Pro | 用于对应的 Pro 设备布局 |
| 红米手表 | 用于对应的 REDMI Watch 设备布局，当前项目以 REDMI Watch 5 为适配目标 |
| 完整版 | 使用预设的云服务器，适合直接使用官方服务 |
| 社区版 | 首次使用云功能时可选择官方或第三方服务器 |

下载页同时提供 AstroBox 和米坛社区入口。不同型号的系统能力可能不同，请核对下载渠道标注的兼容设备，不要仅凭屏幕外形选择安装包。

## 安装并完成第一次运行

1. 使用支持该设备的快应用安装工具连接手环或手表，例如 AstroBox。
2. 选择刚下载的 `.rpk` 文件，按工具提示安装。
3. 在设备应用列表中打开 JSLab。首页为空是正常情况，表示还没有本地脚本。
4. 按照 [第一次使用 JSLab](getting-started.md) 新建并运行一个计数器。

不想马上写代码，也可以打开设备首页左下角的 JS 市场，或先在网页 [浏览市场作品](https://ccicc.icu/jslab-cloud/workspace/market)。市场下载到设备后，还需要从本地脚本列表打开运行。

## 按需要添加配套工具

- **想在 Android 手机上编辑：** 在 [下载页](https://ccicc.icu/jslab-cloud/downloads) 获取 Android 同步器，并阅读 [手机与 AstroBox 同步](sync-guide.md)。它依赖小米运动健康中的设备连接。
- **已经使用 AstroBox：** 在 AstroBox 插件源中获取 JSLab Sync。也可从 [插件发布仓库](https://github.com/cciccicu/JSLab-AstroBox-Plugin-Release) 获取安装包。
- **想在电脑浏览器里编辑：** 阅读 [云账户与云空间](cloud-guide.md)，完成登录、激活和设备配对。

配套端中的“保存到设备”和云空间中的“保存文件”作用于不同位置。选定一种工作方式后，先用一个测试文件走完编辑、传输和运行的流程。

## 更新已有安装

更新前，先把需要保留的脚本下载或导出到手机、电脑。脚本源码与脚本保存的数据是两类内容；记录也很重要时，请使用同步器单独导出数据。

使用与原安装相容的安装包进行更新。遇到签名不匹配时，先核对安装包来源；不要为了更新而直接卸载仍有重要数据的应用。完整版和社区版使用相同应用包名，不应当作两个相互独立的存储空间。

需要编辑脚本数据等新功能时，设备端和同步器都应更新。若只想查看操作方法，可直接前往 [管理脚本与使用编辑器](watch-guide.md)。
