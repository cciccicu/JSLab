# 云账户与云空间

> 最低支持版本：设备端的配对、激活及云文件操作以 JSLab 2.0.0 为基线。仅使用网页无需安装设备端；社区版选服说明见下文。

云空间是一份保存在服务器上的脚本库。你可以在手机或电脑浏览器里写代码，在设备上下载运行；也可以把设备上的脚本主动上传，留作备份或继续编辑。

开始操作：[打开云空间](https://ccicc.icu/jslab-cloud/workspace)。还没有安装设备端时，先查看 [选择版本与安装](installation.md)。

## 分清登录、配对和激活

登录让网页知道你是谁；配对让设备可以访问你的账户；激活用来开通云空间和内置 AI。本地编辑、运行脚本不需要完成这些步骤。

Android 同步器和 AstroBox 插件可以直接管理设备文件，不要求激活云空间。具体步骤见 [配套端同步指南](sync-guide.md)。

## 把手环连接到自己的账户

1. 在手环打开 JSLab 的云设置，点击“生成配对二维码”。
2. 用手机扫描二维码，打开网页并登录。
3. 确认配对，然后回到手环，等待出现配对成功的提示。

不方便扫码时，也可以登录 [云空间](https://ccicc.icu/jslab-cloud/workspace)，打开“设备管理”，输入手环显示的 8 位配对码。

配对码过期了就重新生成。网页确认之后，还要等手环显示成功，才能开始使用。以后不想让某台设备继续访问账户，可以在“设备管理”中撤销它的授权。

## 激活云空间

在网页云空间点击“充值与激活”，输入有效激活码兑换。官方服务首次有效兑换会开通云空间和 AI，并赠送 ¥2.00 的 JSLab 额度；之后每个未使用的激活码增加 ¥3.00。

还没有激活码？可以 [购买激活码](https://catfk.com/shop/788UHUA9)，购买后回到“充值与激活”兑换。

兑换完成后，在手环云页面刷新账户状态，就能看到更新后的激活状态和余额。

## 在网页上写代码，在手环上运行

1. 打开网页云空间，点击“新建”。
2. 输入文件名，例如 `hello.js`，写入代码后点击“保存文件”。
3. 在手环打开云空间，刷新文件列表，选择刚才的文件并下载。
4. 回到手环本地工作区，打开下载的文件，点击运行。

下次在网页上修改后，保存云文件，再在手环重新下载。手环上改过代码，也需要主动上传，网页里才会看到更新。

**上传和下载都需要你亲自操作。** 编辑或保存本地文件后，云端不会自动跟着修改。两边都改过同一个文件时，先确认要保留哪一份，避免覆盖需要的内容。

## 整理云文件

在搜索框输入文件名，可以快速找到文件。点击“编辑”修改名字或代码，再点击“保存文件”；删除按钮也在编辑窗口中。

文件名以 `.js` 结尾，尽量简短、容易辨认，例如 `计数器.js`。名字最长 128 个 UTF-8 字节，中文通常占 3 个字节；脚本源码不设固定字节上限，实际传输和运行受服务配置、设备内存及可用存储影响。超过 48 KiB 的脚本在手环打开编辑页前会提示，确认后仍可编辑。

云空间没有历史版本或回收站。覆盖、删除重要文件前，先导出到手机或电脑，或另存为需要保留的副本。

## 社区版与第三方服务器

社区版在首次使用云功能时选择官方或第三方服务器，最低支持版本为 JSLab 2.0.2 社区版。

社区版首次使用联网页面时会让你选择官方或第三方服务器，也可以在“设置 > 云账户”中更换。使用哪个服务器，就要登录该服务器的网页并在那里完成配对。

更换服务器后需要重新配对。原服务器的文件、激活状态和额度不会自动迁移；第三方服务器的服务规则以其说明为准。

## 下一步可以做什么

网页编辑器用于编辑源码，不能代替设备运行脚本或验证设备接口。保存云文件后，先下载到设备运行，再继续分享或打包。

- 在手机上直接编辑设备文件，或让手机转发云服务请求：[手机与 AstroBox 同步](sync-guide.md)。
- 让 AI 帮你起草或改写：[使用 AI](ai-guide.md)。
- 发布作品、查看审核结果：[市场使用指南](market-guide.md)。
- 做成能独立启动的应用：[导出为独立应用](rpk-guide.md)。
- 配对失败、无法连接或文件没有更新：[常见问题与排查](troubleshooting.md)。
