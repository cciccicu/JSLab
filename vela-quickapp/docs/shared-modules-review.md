# 快应用公共 JavaScript 复查

本记录对应大型模块复查轮次；后续小型模块的合并与修复见
[小型公共模块复查](small-shared-modules-review.md)。本记录安装包快照位于
`release-archive/shared-module-review/`，`dist/` 将随后续同版本构建更新。

本轮沿 `src/pages/**/*.ux` 的 import、页面使用的组件及 `app.ux` 启动引用追踪公共 JS。
手工复查模块职责、内部命名、调用方、成功/失败分支和已有数据的读写规则。
已完成的统一运行器、UI 编译/发布、日志、对话框和云服务端迁移不重复改造；
帮助资料、脚本模板和 2048 示例也沿用前轮结果。

## 调整后的边界

新增五个职责明确的文件，调用方均已更新，不保留旧位置的重复实现：

| 新模块 | 内容 | 实际使用方 |
| --- | --- | --- |
| `editor/fontProfile.js` | 默认字体资料、归一化、校验与 `readActiveFontProfile()` | 主编辑器、字体设置及字体包管理 |
| `editor/highlightPalette.js` | 四种配色与预设选择 | 主编辑器、高亮设置、词法高亮器 |
| `cloud/cloudTransport.js` | 云地址、认证头、原生 fetch/桥接、响应解析与错误说明 | 云业务模块 |
| `files/scriptTransfer.js` | 文件 RPC、数量受限的上传会话与 UTF-8 读取分块 | 原生桥接 |
| `files/textEncoding.js` | UTF-8 字节数/字符边界分块与严格 Base64 解码 | 文件模块、字体包及首页文件名提示 |

`fontManager` 负责待安装包、磁盘续传和 Helper 安装交付，这些功能共有同一组状态与协议，
继续放在一个模块。`companionBridge` 保留字体请求串行交付适配，与原生消息关联；
不再承担脚本文件业务。`cloudService` 不再向页面暴露通用 `request`，
仍提供页面实际需要的业务方法及相应错误说明。

这些边界减少不必要的引用和修改耦合；应用启动仍会初始化桥接，不能据此声称
整个应用首次加载时间、手环内存或帧率已经改善。

## 修复的功能问题

1. **普通云下载缺少完整性校验。** 与市场下载共用 checksum 校验规则，服务器提供了
   校验值时必须格式正确且与 UTF-8 源码匹配，否则不写文件。缺少校验值的旧响应继续可读。
2. **异常配对成功响应能覆盖已有令牌。** 保存前要求非空字符串，失败保留已有令牌。
   传输层拒绝非对象/数组 JSON，业务层拒绝异常列表与权益结构，不再显示空列表假成功。
3. **AI 被普通桥接超时提前终止等待。** 普通请求保留 20 秒；AI 使用 330 秒，覆盖云端
   最多 300 秒的模型请求及传输余量。期限只作为快应用本地参数，不改变 cloudProxy 消息。
   超时文案不再写错成固定 30 秒；发送同步抛错或失败会立即撤销对应计时器和待返回记录。
4. **历史长中文文件名只能读、不能保存。** 已有文件超过 128 UTF-8 字节时额外检查存在性，
   允许原名保存；新建和改为超长名字仍拒绝。正常文件名不增加原生文件查询。
5. **字体续传状态接受字符串索引和非有限数。** 校验整数、范围、实际块数和累计字节关系；
   不合格状态沿既有重新上传流程处理。待安装元数据也核对块数与分块大小。
6. **Base64 接受中间 padding 或非规范末尾位。** 解码与字体包写入归属同一流程，
   先校验再写入，避免两份“解码后的内容/落盘编码”脱离；外部上传消息不变。
7. **词法/拼音/错误查表命中继承属性。** 高频词法查表使用初始化一次的无原型字典；
   原词典使用 own-property 判断，避免复制整个词典。`constructor` 等文本不再误判或触发候选异常。
   高亮增加当前脚本的 `ui/dialog/script/system/globalThis` 名称，并把预算上限固定为 4096。
8. **UTF-8 分块可能永远不前进。** 偏移必须是非负整数字节，预算不足以容纳下一个字符时
   明确报错；不会返回 `done=false`、偏移不变的空块。正常 4096 字节读取路径不受影响。
9. **数组配置保存丢字段。** 配置根数组降为有效的空配置，待写入路径上的数组重建为对象；
   正常已有对象及未知字段沿原快照读写方式保留。
10. **桥接分块日志的额外开销。** 发布默认关闭跟踪日志和启动诊断，保留错误；
    删除为日志计算“bytes”的整块 JSON 序列化。保屏跟随原生连接打开/关闭和初始 ready-state，
    不在每条消息重复调用。连接关闭不重置仍可能有磁盘操作的字体串行队列。
11. **字体设置离开后继续轮询。** `onHide` 停止页面的心跳/安装轮询，`onShow` 按原生生命周期恢复。

## 保留的取舍

- 脚本读取 RPC 每块仍通过原生 `readText` 读取整个文件；大脚本的多块读取存在重复 I/O
  与扫描。现有原生文档没有偏移文本读取接口，没有在缺少实机需求下增加大文本缓存/读取会话。
- 脚本上传仍按声明字节数和顺序接收，在完成时合并整段文本；会话数量受限，不新增脚本大小限制。
  不增加并发保存、通用取消或旧任务回滚框架。
- 高亮是有预算的近似词法着色，模板字符串和正则上下文不等同完整 JS parser。
  光标几何按现有字体与 UTF-16 估算，复杂 emoji/组合字符的宽度、光标位置不是精确测量。
- 330 秒本地等待不取消服务端模型请求；中途断连仍可能出现云端继续完成生成。
  fetch 没有在现有原生文档中提供可设 timeout，不添加虚构参数或伪取消层。
- 原生连接、手势、路由、滚动继续交给 Vela，没有为这些行为新增手动状态机。
