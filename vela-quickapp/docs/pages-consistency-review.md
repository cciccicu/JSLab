# 全页面视觉与逻辑一致性复查

本轮完整读取 manifest 中的 21 个页面的 template、script、style，以及共享 dialog.css。
同时核对路由、编辑器资料、对话框交付和时钟调用。检查对象是快应用源码；
没有用浏览器、桌面模拟器或桌面性能数字代表 Vela 原生效果。

后续实机反馈暴露出二维码尺寸改错，以及对话框样式没有编译、模块局部状态没有跨页面共享。
这说明本报告原先的源码检查不足以证明对话框可用；现已修复并更正相应条目，
详见 [对话框回归修复](dialog-regression-fix-2026-10-06.md)。

## 统一规则与修复

- **页面外观与层级。** 内容在前，顶栏背景、时钟、标题和触控按钮随后；所有页面的
  顶部按钮维持 72×72、6px 边距。普通滚动内容从 84px 开始，按钮下缘到内容起点也为 6px。
  没有底部工具栏的页面使用 24px 底部留白；首页、云文件和编辑器仍保留操作区。
  运行器脚本隐藏顶栏的自由度不变，输入法仍使用供应方组件和其原有区域。
- **时钟。** 21 个页面统一在 onShow 启动、onHide/onDestroy 停止分钟时钟。
  time.js 只增加 startPageClock/stopPageClock，WeakMap 保存句柄，按分钟边界刷新，
  文本不变时不发布。恢复页面立即校时，长时间填写对话框也会刷新。
  这属于显示时钟的共同职责，没有添加页面基类、通用任务清理或全局导航状态机。
- **编辑行为。** 三个编辑器运行当前源码快照，运行不写磁盘；保存单独交付。
  顶栏与系统返回共用“先收起键盘，再收起光标控制，再处理未保存修改”。
  不保存退出时都恢复共享编辑缓冲到已保存内容。保留三版本各自的高亮/字体能力差异。
  v1 隐藏后停止光标闪烁，恢复时启动；v2 的闪烁和滚动定位也限于可见页面。
- **编辑器操作。** v2 右上角恢复页面内浮层菜单，提供 AI 生成、另存为、编辑器设置；
  点空白或返回可关闭菜单。另存为复用保存忙碌状态，避免重复写入；
  完成后再切换文件名与锁。长名字不会在打开输入对话框时因为默认副本名过长而直接失败。
  新建/编辑标题与 toggleKeyboard、toggleCursorControls、save、run 等名称统一。
- **编辑恢复。** v2 偏好读取失败时仍准备当前源码视图，避免空白页；
  保存、另存为和旧编辑器保存完成后不再操作已销毁页面。
  点击代码使用原生 offsetX/offsetY，去掉额外的 6px 横向扣减。
  字体字宽仍为既有估算，不声称能精确测量任意字体或模拟原生命中坐标。
- **字体打包与备份。** 本轮初次构建发现额外字体副本；构建资源跟踪确认，工具链也扫描了
  我放在项目内的 `.ux` 源码快照，因而将备份引用的字体收集到 dynamicAssets，多出约 1.1 MiB。
  源码快照改为逐文件 SHA-256 核对的 source-snapshot.zip，展开快照的 UX 文件改为
  `.ux.snapshot` 扩展名保留，然后重新执行正式构建。AGENTS.md 补充这一备份约束。
  当前 font-face 使用应用资源绝对路径 `/common/fonts/active.ttf`，编译后仍是与前轮相同的
  字体地址；字体文件和 Helper 目标不变，不在签名包中手动删除资源或修改工具链。
  最终核对包中只保留一份字体。
- **新建与首页。** 创建后 replace 到配置的编辑器，退出编辑器回首页，不返回保留旧文件名
  的创建表单。编辑器配置读取失败时回退 v2；等路由读取完成且来源页面有效后才设置共享缓冲。
  新建键盘按需挂载，文件名累计输入有长度限制；最终文件名合法性/UTF-8 字节预算仍由 jsManager 负责。
  首页读取后打开编辑器/运行器的逻辑合并，有忙碌提示和可见性判断；隐藏首页不因文件通知
  刷新响应式列表。空态改为“暂无脚本”，长错误有界显示，已有列表不被错误覆盖。
- **云与市场。** 云账户、云文件、AI、市场只在初次展示自动读取；唤醒不反复请求。
  用刷新按钮或服务状态卡片主动刷新，成功配对、退出、切换传输、删除后仍主动刷新。
  市场、云账户在读取配置阶段已有请求锁；云文件刷新期间清除旧选中项，避免操作隐藏的旧目标。
  市场右上角为发布入口，刷新位于搜索栏旁；云文件仍用右上角 rerun 刷新图标，忙碌与禁用样式对应实际守卫。
  云账户配对轮询在隐藏时暂停；恢复先检查过期，再继续原配对码。
  原有配对/传输/校验协议和 AI 计费行为不变，不虚构服务端请求取消能力。
- **设置与提示。** “登录”入口改为与目标页一致的“云账户”，提示也指向云账户页。
  编辑器设置不在读取或保存期间发起新的版本/字号修改；高亮设置保存回调忽略已销毁页面，
  值未变化时不重复保存。字体安装按钮使用统一主色，Helper 心跳/安装轮询沿用既有原生生命周期。
- **正文与分页。** 帮助正文卡片内容宽度改为 292px，与 324px 卡片和两侧 16px padding 对齐。
  帮助通过原生 scrollTo 回到顶部，删除销毁/重建 scroll 的做法；选择对话框后续按用户要求
  改为原生 list 连续滚动，移除分页按钮和相关状态。捐助二维码原本使用原生默认尺寸，错误增加的 220×220 样式
  已根据实机反馈撤销；二维码和父容器恢复原样，欢迎文字也恢复原有行高及单行显示。
  关于页删除固定标题无须使用的 marquee 分支，版本仍来自 app.getInfo。

通过 lint、现有页面结构检查和运行契约静态检查。
