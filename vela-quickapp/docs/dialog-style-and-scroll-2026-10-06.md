# 对话框原有视觉风格与连续滚动

按用户要求保留原有高度一致的对话框视觉风格，选择项连续滚动，取消点击分页。
样式依据修改前 Git 源码中的颜色、圆角、字号、选中图标和确认页操作排列。

- 四页共用原有黑底顶栏、灰色 `#262626` 卡片、蓝色 `#0d6eff` 主操作与选中态。
  选择项恢复 36px 圆角、32px 标题和 40px 图片勾选；输入卡片恢复 36px 圆角，
  文字输入恢复深色输入区域。确认页恢复底部横排按钮，双动作及三动作都保持横排。
- 选择对话框使用原生 list/list-item 展示全部最多 100 项，滚动、回弹和节点复用交给 Vela。
  删除分页按钮、页码、分页方法、分页样式、scrollTo 复位及 pageItems 契约字段。
  列表项使用稳定 tid 和明确高度，相同 type 的子树一致；描述/勾选使用 show，避免条件
  子树影响原生复用。多选计数在列表说明区域显示，选项的业务值仍留在普通 JS 缓冲。
- 单选只发布旧项和新项的选中字段；多选只发布本次操作项，整个列表不重复重建。
  仍支持描述、禁用、多选、数量约束和确认提交；数字的负数/小数、文字的光标/清空也保留。
- 应用共享请求、dialogId 核对、异常退出释放和 @import 样式修复完整保留，二维码不再调整。
- 设备帮助、运行契约文档、方案/实现记录及云端 AI 提示词同步更新。公开 API 和持久化格式不变，
  不需要数据迁移；应用仍为 1.9.3 / 193，插件仍为 0.5.1。云插件覆盖后通过 PM2 重启读取提示词，
  无需再次执行 install。

仅进行源码 lint、真实样式编译/请求协议检查和正式打包核对，不运行桌面 UI 模拟或设备部署。
长列表的实际滚动、卡片显示和输入法效果仍以实机为准。
